# ⚡ Elektronica & Elektrotechniek Formuleblad

| Grootheid | Formule | Eenheid | Opmerkingen |
|-----------|---------|--------|------------|
| **Stroom (constante)** | $$I = \frac{Q}{t}$$ | A | Q = lading (C), t = tijd (s) |
| **Lading** | $$Q = I \cdot t$$ | C | Voor constante stroom |
| **Capaciteit condensator** | $$C = \frac{Q}{U}$$ | F | Q = lading, U = spanning |
| **Spanning condensator** | $$U = \frac{Q}{C}$$ | V | |
| **Verandering spanning condensator** | $$\Delta U = \frac{I \cdot \Delta t}{C}$$ | V | Voor constante stroom |
| **Spanning over condensator bij wisselstroom** | $$\hat{U}_C = \frac{\hat{I}}{\omega C}$$ | V | $$\omega = 2 \pi f$$ |
| **Stroom door spoel bij wisselspanning** | $$\hat{I}_L = \frac{\hat{U}}{\omega L}$$ | A | $\hat{U}$ = amplitude spanning |
| **Reactantie spoel** | $$X_L = \omega L$$ | Ω | ω = hoekfrequentie (rad/s) |
| **Reactantie condensator** | $$X_C = \frac{1}{\omega C}$$ | Ω | ω = hoekfrequentie |
| **Gemiddeld vermogen weerstand (AC)** | $$P_\text{gem} = \frac{\hat{U}^2}{2R} = I_\text{rms}^2 R$$ | W | \(\hat{U}\) = amplitude spanning |
| **Magnetische kracht op draad** | $$F = B I l \sin\theta$$ | N | B = veldsterkte (T), l = draadlengte (m) |
| **Magnetisch veld rondom lange draad** | $$B = \frac{\mu_0 \mu_r I}{2\pi r}$$ | T | r = afstand tot draad (m) |
| **Magnetische flux** | $$\Phi = B \cdot A \cdot \cos\theta$$ | Wb | A = oppervlak lus (m²), θ = hoek normaal t.o.v. B |
| **Inductiespanning** | $$U_i = -N \frac{d\Phi}{dt}$$ | V | N = aantal windingen |
| **Zelfinductie lange spoel** | $$L = \mu_0 \mu_r \frac{N^2 A}{l}$$ | H | N = windingen, A = doorsnede (m²), l = lengte (m) |
| **Spanning over spoel bij wisselstroom** | $$\hat{U}_L = \omega L \hat{I}$$ | V | Amplitude, fase +90° t.o.v. stroom |
| **Spanning over spoel bij constante stroomverandering** | $$U_L = L \frac{dI}{dt}$$ | V | dI/dt = snelheid van stroomverandering |
| **Rendement** | $$\eta = \frac{P_\text{load}}{P_\text{source}}$$ | - | 0 ≤ η ≤ 1 |
| **Thévenin spanning** | $$U_T = U_\text{open}$$ | V | Spanning open klemmen |
| **Thévenin weerstand** | $$R_T = \frac{U_T}{I_\text{kort}}$$ | Ω | Of alle bronnen nul en vervangingsweerstand meten |
| **Batterij energie** | $$W = \frac{1}{2} C U^2$$ | J | Condensator / accu |
| **Batterij energie (Wh)** | $$W_\text{Wh} = \frac{W_\text{J}}{3600}$$ | Wh | 1 Wh = 3600 J |
| **AC phasor optelling** | $$\hat{U}_\text{tot} = \sqrt{(U_{1x}+U_{2x})^2 + (U_{1y}+U_{2y})^2}$$ | V | $$U_x = \hat{U}\cos\phi,\ U_y = \hat{U}\sin\phi$$ |
| **AC phasor fase** | $$\phi_\text{tot} = \arctan\frac{U_{1y}+U_{2y}}{U_{1x}+U_{2x}}$$ | ° | Let op kwadrantcorrectie! |
